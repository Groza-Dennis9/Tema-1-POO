# Merging Cat Game

## 📸 Overview 📸
- A terminal style game where, based on your selection from the menu, you merge cats!

## ✨ Mechanics ✨
- **Rescue** : adds a level 1 cat to the game when a free spot exists
- **Merge** : combine two cats of the same level to create a cat of a higher level
- **Clean** : the amount of cats that have been on one spot in the shelter will decrease its cleanliness. If it is bellow 20, a new cat can't be rescued there.
- **Game Over conditions** : reach the level 6 cat or for the shelter to become full of cats that *can't* be merged

## 🛠️ Technical skills 🛠️
- **Languages** : C++
- **IDE** : CLion
- **OOP Concepts** : Basic ones - constructors with destructors, setters, getters, operator overload, encapsulation
